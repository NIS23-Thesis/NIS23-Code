# CLIVE shared application shell

The shared site header is generated by `clive/scripts/sync_ui_shell.py` for all four
HTML entry points (Experiment Setup/Run History, Topology, Learning and Events).
The canonical CSS is `clive/ui_shared/shell.css`. Edit the generator or the
canonical stylesheet, then rerun:

```bash
python clive/scripts/sync_ui_shell.py
```

Do not independently copy or hand-edit site headers: the generator maintains
identical brand, navigation labels, run picker, spacing and selected states.
The usual launcher serves all pages from `http://127.0.0.1:9767/`.

## Navigating results

Each page shows exactly one run picker at the same position in the header.
Selecting a run on Setup or History opens its Topology; selecting on a result
page updates that page and the shared selection used by other result pages.

New experiment output folders are `run-1`, `run-2`, ... under the configured
results root. The counter is durable in `results/_control/run-counter.txt` and
allocation is concurrency-safe on POSIX. Existing legacy random-name result
folders are preserved and remain accessible; they are not renamed, and no
existing links or saved evaluation data are rewritten.
