How these model metrics are measured

The optional CLIVE learning recorder runs inference on a deterministic held-out MNIST test subset (512 images in the panel presets) after each model revision. Macro scores give all ten digits equal weight (zero for undefined class metrics); weighted F1 weights by actual label counts. The final metric uses 10,000 test images when enabled. It does not train or change FLAME. The separately reported final accuracy uses the entire 10,000-image held-out MNIST test split. Repeatedly inspecting test accuracy can influence hyperparameter selection, so treat the per-update curve as diagnostics, not an unbiased final benchmark.

FLAME protocol code is untouched. Accuracy points appear only if CLIVE recorded them. Sensor Nodes do not train models.
