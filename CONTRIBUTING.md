# Ticket Conventions

Each ticket is typically issued per submodule within CLIVE and FLAME, should a submodule be too large it may be fragmented into additional tickets, the tickets will indicate as such. Each module will then have a ticket concerning its integration. Once each module is verified, inter-module integration will be issued in multiple tickets.

# Commit conventions

Commits made to this repo MUST follow [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/)

For example: a feature implementation for the communication for for FLAME was made, it's title must be 

`feat(flame): implemented parsing submodule of communication`
